# Design Direction — Skate Journal

기능보다 **미학**이 중요한 프로젝트다.

## 원칙
- 스케이트 zine, 사진집, 필름 사진의 감각을 참고한다.
- 타이포그래피와 사진이 주인공. UI 장식은 최소화.
- 공개 페이지는 "읽는 작품"처럼. 입력 화면은 빠르고 단순하게.
- 공개 페이지와 입력 화면은 다른 디자인 기준을 가져도 된다.

## 결정 전 열린 질문
- 톤: 거친 zine(콜라주, 흑백, 손글씨) vs 정제된 사진집(여백, 큰 이미지)
- 서체: 한글/영문 조합
- 사진 표시: 풀블리드 vs 그리드 vs 인쇄물 같은 배치

시안을 만들 때는 `references.md`의 패턴을 근거로 삼고, 어떤 레퍼런스에서 무엇을 가져왔는지 적는다.
