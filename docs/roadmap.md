# Roadmap — Skate Journal

현재 단계: **M0 초기 설정**

| 단계 | 내용 | 상태 | 목표일 |
|---|---|---|---|
| M0 | 초기 설정 (`initialsetup.md`) + 스택 확정 | 진행 중 | |
| M1 | 레퍼런스 수집 범위 확정 + 1차 수집 (앱, 웹사이트, 도서, 국가별 씬) | 대기 | |
| M2 | 콘텐츠 스키마 확정 + 샘플 콘텐츠로 연결 구조 동작 확인 (스타일 없이) | 대기 | |
| M3 | 첫 글 1편 + 세션 2~3개 + 사진 연결 | 대기 | |
| M4 | 디자인 시안 2~3개 → 1개 선택 | 대기 | |
| M5 | 공개 페이지 + 공유 (private 제외 확인) | 대기 | |

## 메모
- 디자인은 연결 구조가 동작한 뒤에 시작한다.
- 디자인 레퍼런스 수집은 M1부터 상시로 진행한다 (`docs/design/references.md`).
